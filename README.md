# EggAI — электрический питомец для Android

EggAI — небольшая игра-питомец на Kotlin. Ухаживай за милым жёлтым электрическим существом: нажимай на него, собирай искры, корми ягодами, тренируй и восстанавливай энергию. Прогресс сохраняется на устройстве.

## Функции
- Тап по питомцу даёт искры; каждые 12 нажатий повышается уровень.
- Показатели счастья и энергии.
- Кормление ягодами: +18 счастья и +12 энергии.
- Тренировка расходует энергию и приносит искры.
- Отдых восстанавливает энергию.
- Покупка трёх ягод за 10 искр.
- Сохранение состояния после закрытия приложения через SharedPreferences.
- Интерфейс рисуется средствами Android; дополнительные изображения или API-ключи не нужны.

## Требования
- Android Studio (рекомендуется актуальная стабильная версия).
- JDK 17 (обычно поставляется с Android Studio).
- Android SDK Platform 35 и Android SDK Build-Tools, которые Android Studio предложит установить.
- Android 6.0 (API 23) или новее на телефоне.

## Открыть и запустить
1. Распакуй архив `EggAI.zip`.
2. Открой Android Studio.
3. Нажми **Open** и выбери распакованную папку `EggAI` (внутри должны быть `settings.gradle.kts` и `app/`).
4. Дождись окончания Gradle Sync. Если Android Studio предложит установить SDK или Build Tools, согласись.
5. Подключи Android-телефон с включённой «Отладкой по USB» или создай эмулятор.
6. Нажми зелёную кнопку **Run ▶**.

## Собрать APK
### Через Android Studio
1. В меню выбери **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
2. Дождись сообщения об успешной сборке.
3. Нажми **locate** в уведомлении. Обычно APK находится в `app/build/outputs/apk/debug/app-debug.apk`.
4. Передай APK на телефон и открой файл. При необходимости разреши установку приложений из этого источника.

### Командой
Из корневой папки проекта, где лежит `gradlew`:
```bash
gradlew.bat assembleDebug
```
На Linux/macOS:
```bash
./gradlew assembleDebug
```
Этот архив не включает Gradle Wrapper JAR и скрипты wrapper. Если команда `gradlew.bat` отсутствует, открой проект в Android Studio: IDE сама загрузит нужные компоненты. Для полноценного wrapper можно в терминале проекта выполнить `gradle wrapper` при установленном Gradle.
